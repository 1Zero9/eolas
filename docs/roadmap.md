# Roadmap

## Implemented foundation

- idea capture, workspace, notes, build brief, and merge controls;
- structured validation decision gate and history;
- versioned accelerator catalogue and immutable assembly plans;
- safe local worker and staged, approved build lifecycle;
- local Git commit and backup to an existing GitHub repository;
- menu-bar app and metadata-only local discovery;
- audit events, tests, signed browser sessions, and setup documentation.

## Next high-value work

1. **Accelerator composition fixtures** — create sample projects that build with common accelerator combinations.
2. **Evidence-assisted validation** — add sourced research capture and decision templates without replacing human judgement.
3. **Plan editing** — support configuration inputs and deliberate revisions rather than recreating a plan from scratch.
4. **GitHub App integration** — create private repositories with least-privilege installation credentials.
5. **Deployment contracts** — add individual, approval-gated providers only after defining credentials, rollback, and audit behaviour.
6. **Worker hardening** — per-worker credentials, rotation, health recovery, and richer job logs.

## Explicit non-goals until the foundation is proven

- autonomous repository-wide code changes;
- arbitrary command execution;
- automatic copying of source code discovered in local repositories;
- unreviewed deployment or external-service provisioning.
